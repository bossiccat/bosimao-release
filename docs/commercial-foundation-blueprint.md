## 2. 目标架构（施工完成后）

### 2.1 安全底座
- 全链路 HTTPS/WSS（后端 + sidecar + pet-ui + Android 四端），自签 CA 过渡，正式 CA 替换。

### 2.2 合规底座
- 隐私四类开关（云端处理 / 麦克风采集 / 后台对话 / 桌面捕获），后端生效 + 前端 UI。

### 2.3 产品底座
- 设置页：设备列表+撤销、运行诊断页（六项）、隐私开关 UI、关于页。

### 2.4 信任底座（品牌化减疑）
- 进程品牌化：客户任务管理器看到的是「贾克斯·星核」家族，不是裸 `python.exe`。
- 目标进程形态：
  - `jax-pet.exe`（桌宠，签名）
  - `jax-rtc-sidecar.exe`（sidecar，签名）
  - `jax-backend.exe`（后端，PyInstaller 打包，签名）
  - `jax-model.exe`（模型服务，签名）
- 卸载清理闭环：卸载时干净清除服务/自启/残留/CM 凭据。

### 2.5 运维底座
- 崩溃上报 + 诊断收集；自动更新（签名后）；服务自愈（无窗口、不弹窗）。

## 4. 关键决策记录（防止再次跑偏）

| # | 决策 | 理由 |
|---|------|------|
| D-1 | 签名前**不**搞无窗口常驻自启 | 无签名 + 自启 + 无窗口 = 杀毒误报 + 信任崩塌 |
| D-2 | 服务化走"服务化常驻"而非"app 统一管理" | 模型服务加载慢需常驻，语音需手机随时连 |
| D-3 | 签名是信任底座的根本解药 | 有签名后常驻特征不再有误报风险 |
| D-4 | 进程品牌化（去掉裸 python.exe） | python.exe 常驻+联网是恶意软件高嫌疑特征 |
| D-5 | 计划任务方式废弃 | 每 5 分钟弹窗是商业化红线 |
| D-6 | 自启必须"可见可控可解释" | 明示开关 + 隐私说明 + 卸载干净 |

## 5. 验收总门（阶段完成标准）

1. 四端 HTTPS/WSS 连通（openssl/httpx 验证）
2. 隐私开关可切换且后端生效
3. 设置页设备管理/诊断/隐私/关于四项齐全
4. 无任何命令窗/指令框弹出（全进程链 GUI/无窗口）
5. 进程名品牌化，无裸 python.exe 常驻
6. 卸载干净（无服务/自启/残留/凭据）
7. 工作区无未提交改动（技术债清偿）
8. 签名后：杀毒零误报 + SmartScreen 通过
