# ADR-007: 宠物视觉 — 有机光球 + 语义色 + 四级渐进打扰

- 状态：已接受
- 日期：2026-08-03
- 决策者：设计师 颜好看 + 架构师 高见远

## 背景

宠物是产品的核心视觉载体。需在"监控时低调、提醒时醒目"之间平衡，且渲染开销低（12G 显存机器，GPU 资源优先给模型）。

## 选项对比（宠物形象 3 方向）

| 方向 | 特点 | 代价 | 结论 |
|---|---|---|---|
| 有机光球（Mico 路线） | 流动的光 + 核心高光；语音 AI 通用语言，信任成本最低 | 同质化风险 | **选中（主推）** |
| 机械核心/浮游哨兵 | 六边形核心 + 雷达眼，开发者气质 | 小尺寸辨识度弱、偏冷 | 备选（硬核皮肤） |
| 抽象几何生命体（Claude 星芒） | 差异化最强 | 动画成本最高 | 融合元素（微表情） |

## 决策

- 主形态：**有机光球**（SVG 径向渐变 + 少量粒子，纯代码绘制零贴图），核心高光可做睁眼/闭眼/关注微表情
- 双态：监控态 64-96px / 20-40% 透明度 / 贴边呼吸；提醒态 120-160px / 100% / 语义色 2Hz 脉冲
- 语义色：success `#34D399` / warn `#F59E0B` / danger `#F87171` / thinking `#818CF8`（Indigo 纯色，P0-2 允许）
- 宠物本体光色：`#2563EB → #38BDF8`（同色系蓝渐变，非紫粉）
- 四级渐进打扰：状态点变色 → 桌宠微动 → 浮起脉冲 → 语音 + 手机推送
- 命名：「星核 Spark」
- 皮肤系统：Lottie JSON + Token 参数，方向 2 哨兵预留在皮肤目录

## 后果

- 正面：信任成本低（Siri/ChatGPT/Mico 同语言）、渲染开销最低、天然契合语音状态机
- 负面：与主流 AI 助手光球同质化 → 用"微表情 + 语义色 + 渐进打扰"形成差异化
- 替代触发条件：用户偏好硬核风格 → 切方向 2 皮肤（零核心改动）
