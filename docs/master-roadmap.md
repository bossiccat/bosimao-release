## 0. 一句话目标

**波斯猫 = 站在 Hermes 肩膀上的商业化移动语音 agent：后台 agent 引擎（Codex 半边）借 Hermes，波斯猫自研移动端端到端语音前台（GPT-Live 半边）+ 商业化产品化，形成「语音对话 → 委派 → 后台干活 → 回报」闭环，达到可商业化交付（杀毒不报、用户信任、可上架）。不做 Hermes 的 fork，做 Hermes 之上的差异化产品。**

---

## 1. 竞争战略定位（2026-08-13 确立，最高优先级，禁止跑偏）

### 1.1 竞争事实（联网核实）

Hermes Agent（Nous Research 开源，7.9k+ stars）v0.20.0「The Herald Release」于 **2026-08-03** 发布，已做到：
- 实时流式 TTS（逐句，首字 < 1s）
- barge-in 打断（用户可插话，agent 知道自己被打断）
- 本地唤醒词（Porcupine）
- 全双工语音对话
- 可插拔 STT/TTS（本地 Whisper / Edge / OpenAI / ElevenLabs）

它更新快（社区驱动 + Nous 全公司之力）、开源、商用不设限，生态在滚雪球（英伟达 NemoClaw、Paperclip 编排器）。

### 1.2 差异化（波斯猫的护城河）

| 维度 | Hermes | 波斯猫 |
|------|--------|--------|
| 技术路线 | 级联管道（STT→LLM→TTS 可插拔，官方反对锁定端到端） | 端到端语音模型（MiniCPM-o 原生 speech-to-speech） |
| 场景 | 桌面 PC 麦克风（CLI/TUI/Studio，sounddevice 采本机音） | 移动手机 App（Android 采集 + TRTC 云中继） |
| 定位 | 开源开发者工具（极客向，hermes_cli 出身） | 商业化消费者产品 |
| 更新速度 | 社区驱动，极快 | 自研，聚焦垂直 |

### 1.3 战略（不 fork，借力）

1. **后台 agent（Codex 半边）→ 借 Hermes**。Hermes 开源、商用不设限。波斯猫**不自造通用 agent 引擎**，把 Hermes 当「后台 agent 引擎」接进来。
2. **语音前台（GPT-Live 半边）→ 波斯猫自研移动端端到端语音**。这是 Hermes 没做深的：移动场景 + 端到端模型。
3. **护城河 → 商业化产品化这层**：代码签名、隐私合规、杀毒零误报、普通用户点开即用、卸载干净。Hermes 开源社区**不会替你做这层**，这是它基因里没有的，也是波斯猫能赢的地方。

### 1.4 红线（违反即打回）

- ❌ 禁止 fork Hermes 做「二次改造」（上游更新太快，fork 永远在追版本、合并冲突，是死路）。
- ❌ 禁止自研「通用 agent 引擎」（重复造 Hermes 已做好的轮子）。
- ✅ 波斯猫的自研范围 = 移动端采集/双工链路 + 端到端模型接入 + 商业化产品化。

## 2. 最终目标（终点）

### 2.1 产品形态

```
波斯猫客户端（商业化移动语音 agent）
├── 语音前台（GPT-Live 类比 · 波斯猫自研）
│     └─ 手机 App（Android 采集 + TRTC）＋ 桌宠 sidecar（桌面中枢）＋ MiniCPM-o（端到端模型）
└── 后台 agent（Codex 类比 · 借 Hermes）
      └─ Hermes 作为后台 agent 引擎（不自造）

闭环：语音对话 → harness 委派 → 后台干活（Hermes）→ 回报前台
```

### 2.2 商业化标准（终点验收）

1. 可代码签名、杀毒零误报、SmartScreen 通过
2. 全进程链无弹窗
3. 隐私合规（四类开关 + 明示 + 卸载清理）
4. 客户任务管理器看到「波斯猫」家族，无裸 python.exe
5. 卸载干净

## 4. 剩余 30%：两条主线

### 线 1 —— 产品化（把「能跑」变「能卖」）

| 阶段 | 内容 | 依赖执照？ |
|------|------|-----------|
| C UI 第二波 | 设备管理 + 诊断页 + 关于页 | 否 |
| D 架构减疑 | 进程品牌化（jax-backend/jax-model）+ 卸载清理 | 否 |
| E 运维底座 | 崩溃上报 + 自动更新 | 否（更新签名后启用） |
| G 签名 + 服务化 | 代码签名 + 服务化常驻 + 托盘可见开关 | **是（营业执照）** |

### 线 2 —— 融合（借 Hermes 做后台，波斯猫做前台）

| 步骤 | 内容 |
|------|------|
| H1 借 Hermes 做后台 agent | 把 Hermes 作为「后台 agent 引擎」接入（不自造），cli 品牌化为 bosimao |
| H2 语音前台接入 | 双工语音作为前台能力，sidecar/rtc_bridge 由宿主托管 |
| H3 委派闭环 | 语音意图 → 委派 → Hermes 后台干活 → 回报前台，会话级关联 + 进度可查 + 可打断 |

### 两条线的关系

产品化（线1）是融合（线2）的前置：先让底座能签名、不弹窗、能卸载，再借 Hermes 融合。
