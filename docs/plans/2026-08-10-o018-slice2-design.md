# O-018 Windows 安全安装编排切片 2 实施计划

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在不把 Secret 放入 argv、环境变量、普通文件、日志或 WebView 的前提下，为 O-018 建立可审计的 Windows 父进程编排：CSPRNG 生成 opaque credential、匿名管道传给一次性 provisioner、等待稳定退出码、失败 fail-closed，并明确后端受保护配置同步仍是独立 blocking 门。

**Architecture:** NSIS 保持 per-user、`RequestExecutionLevel user`，只调用受管的 Rust launcher；launcher 在最终交互用户 token 下运行，生成 Secret 后通过 `CreatePipe`/继承的标准输入启动固定 helper，不把 Secret 放入命令行或父进程全局环境。launcher 只负责本地 pipe/handle 生命周期、退出码和清理；后端受保护 secret setting 通过独立部署编排输入，不新增 API，不由 launcher 猜测或回显。

**Tech Stack:** Rust 2021、Tauri 2、`windows` crate 0.61.3（按实际 API feature 编译）、`zeroize` 1.8.1、NSIS 3.11、现有 `provision_sidecar_credential.exe`。
